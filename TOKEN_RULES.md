# Design Token Rules

1. Design tokens are global and shared by all components.
2. Components must never use hard-coded CSS values.
3. All spacing, color, typography, and radius values must come from tokens.
4. Tokens define the design language, not component behavior.
5. Tokens are stable and should not be changed frequently.
6. New components must adapt to existing tokens.
7. Tokens are framework-independent and CSS-first.
