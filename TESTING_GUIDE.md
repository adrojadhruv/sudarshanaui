##  Try the Collaboration Workflow

Experience how users can contribute to the library:

### 1. The Proposal (Log in as Basic User)
1.  Log in with **`user@sudarshana.com`**.
2.  Browse the "Explore" page and click on any component.
3.  Click the purple **"Propose Change"** button.
4.  You are now in **Collab Mode**. Make an edit (e.g., change the color).
5.  Click **"Submit Proposal"**.

### 2. The Owner Review (Log in as Verified User)
1.  Log out and log in with **`verified@sudarshana.com`** (The Owner).
2.  Go to the **"Requests"** tab in the navbar.
3.  You will see the incoming request!
4.  Click **"View Code"** (Orange Badge) to inspect the proposed changes.
5.  Click **"Approve"** to send it to the system administrators for final merge.

> *Note: After Owner Admin approval, the changes are merged and the version is bumped automatically.*

##  Role-Based Access Control (RBAC) Checklist

-   [ ] **Guest**: Can only view the Public Gallery. Cannot see "Create New" or "Requests".
-   [ ] **Basic User**: Can View Details but cannot Edit or Create.
-   [ ] **Verified User**: Can Create new components.
-   [ ] **Admin**: Has full access.
